A. CHẠY HÀNG NGÀY (máy đã cài đặt xong)
-------------------------------------------------

Bước 1. Mở Terminal, vào thư mục project:

    cd "/Users/damthinh/Documents/Công việc/JVB /Dự án BrSE/tech-store-management"

Bước 2. Bảo đảm MySQL đang chạy:

    brew services list

    brew services start mysql

Bước 3. Chạy website:

    php artisan serve

Bước 4. Mở trình duyệt, vào:

    http://127.0.0.1:8000

Bước 5. Muốn tắt website: quay lại Terminal đang chạy, bấm Ctrl + C.

-------------------------------------------------
C. CÀI ĐẶT LẦN ĐẦU (máy mới, vừa tải code về)
-------------------------------------------------

Phần mềm cần có (macOS):

    brew install php          (cần PHP 8.3 trở lên)
    brew install composer
    brew install mysql
    brew services start mysql

Không cần Node/npm.

Các bước:

    cd "/Users/damthinh/Documents/Công việc/JVB /Dự án BrSE/tech-store-management"

    composer install
    cp .env.example .env
    php artisan key:generate

    mysql -u root -e "CREATE DATABASE mini_sales CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"

    php artisan migrate --seed
    php artisan storage:link

    php artisan serve

Giải thích:
  - composer install        : tải thư viện (thư mục vendor/)
  - cp .env.example .env    : tạo file cấu hình
  - key:generate            : tạo khóa bảo mật cho ứng dụng
  - CREATE DATABASE ...     : tạo database rỗng tên mini_sales
  - migrate --seed          : tạo các bảng + nạp dữ liệu mẫu
  - storage:link            : cho phép hiển thị ảnh sản phẩm đã upload
  - serve                   : chạy website

Mặc định .env dùng MySQL: user root, KHÔNG mật khẩu, database mini_sales.
Nếu MySQL của bạn khác, sửa DB_USERNAME / DB_PASSWORD trong file .env.


-------------------------------------------------
D. CÁC LỆNH HAY DÙNG
-------------------------------------------------

Làm mới toàn bộ dữ liệu demo (XÓA hết dữ liệu hiện có, tạo lại từ đầu):

    php artisan migrate:fresh --seed

Chạy test tự động:

    php artisan test

Xem danh sách Route:

    php artisan route:list

Xem riêng Route của sản phẩm (liên quan Câu 5, 6 trong bộ câu hỏi):

    php artisan route:list --path=products

Xóa cache khi sửa .env mà không thấy tác dụng:

    php artisan config:clear

Đổi cổng nếu cổng 8000 đang bận:

    php artisan serve --port=8001
